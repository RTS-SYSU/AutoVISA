## 第一条可运行流程

空白或 JSON MSA → 编辑符号、条件、分析定义与目标 → 差异预览和逐项核对 → 冻结 → 能力检查 → Analysis IR → 真实 Rocq 声明检查 → 保存原始回执和开放目标。

既有案例工作台作为兼容入口保留。通用 MSA 不继承其默认条件，也不要求虚构的 PDF 引用。

## 已授权的验收 Interface

- MSA 工作流：创建、读取、预览、保存、冻结、导出；验证修订与人工作出决定的行为，不能证明自然语言解释正确。
- 结构化形式映射：能力判定、类型检查、声明生成、证据读取；验证输入到精确目标的对应，声明通过不等于目标成立。
- 本地 Web：与上述相同 Interface；验证输入、修订和证据可用。
- Rocq：实际编译、精确类型、内核、假设及依赖审计；验证形式结果，不替代对论文含义的人工核对。

按用户已明确的验收流程，以小纵向切片执行 red → green。旧案例和正式目录保持原样。

## Prosa 使用政策

已获授权适配其定义、通用引理和分析定理。独立构造路线隔离覆盖主要目标的现成定理；库复用路线允许适用定理，并明确记录模型对应、前提、版本与实际依赖。改变用户数学范围仍需具体确认。旧运行保留其原始库政策，新政策仅影响新运行。
