# W05-c：父子运行比较

2026 年 11 月 11 日。本工作包将关联运行的变化保存为可重开的比较记录，覆盖模型与目标、推导图与路线、证明与开放义务、预算与实际用量。比较读取原始记录，不提交新的证明检查，也不改写运行、路线或证据。

## 使用

在项目根目录执行：

~~~powershell
.\check-w05c.ps1
.\start-workbench.ps1 -W05cDemo
~~~

看到 ready 后，打开 http://127.0.0.1:8765/reasoning?run=1ca0c0b2ea6e48d0b8863ca7837e36e1 ，点击“比较父子运行”。演示数据来自本次成功验收，首次启动复制到独立目录，之后启动保留演示中的比较历史。正式工作台仍使用不带演示参数的启动方式。

1. 选择父、子两侧的明确路线版本。父路线默认采用提案时的版本，子路线默认当前保存版本。
2. 点击“生成并保存比较”。页面地址变为比较记录 ID，可刷新、收藏和重开。
3. 阅读四类差异，展开相同内容、原始回执及未直接复用原因。
4. 点击“打开固定路线”查看当时的图和开放义务；该视图锁定路线选择，另有“查看当前路线”入口。
5. 调整比较版本并再次生成时，另存比较；“已保存比较”保留旧观察结果。

只比较由实际采用记录连接的直接父子运行。尚无完成记录的登记运行不能生成比较。不同父子分支分别从相应子运行进入。

## 比较内容与解释

| 类别 | 实际比较内容 |
|---|---|
| 模型与目标 | 形式模型、范围选择、分析定义、来源与语义绑定、形式符号对应、主要目标和全部登记目标；同时列出冻结、映射、语义修订、证明上下文和检查环境版本 |
| 推导图与路线 | 按稳定身份比较节点、精确命题、来源键、连接方向、联合前提、对齐实例化及条件；另行比较两侧所选路线 |
| 证明与开放义务 | 新完成和重新开放的命题、目标修订、完整证明回执、条件证明、两侧共用回执、子运行新增回执、只保留于父运行的历史回执及排除原因 |
| 预算与用量 | 各轮检查限额、实际证明尝试、外部调用、费用、耗时、结果状态和停止原因；分别展示父链已知累计量和费用未知的历史运行数量 |

比较使用精确记录内容，不按名称猜测数学等价性。相同命题重新检查后得到新回执，不计为“新完成命题”。工作台区分“条件充分性通过”和“完整证明通过”。

每个根目标都按指定路线计算开放义务，并区分：

- 新增开放义务。
- 仍待完成的义务。
- 有实际完整证明的原义务。
- 移出所选路线、但没有完整证明的原义务。

例如，拆分桥接后，原 response_bridge 不再是开放叶节点，但仍未被完整证明；比较显示新增的服务下界与上界，并明确标注原义务“移出所选路线（不等于已证明）”。

反向对齐的比较同时显示旧连接移除、新待证连接加入、实例化待建立、依赖原方向的命题重新开放，以及原回执未被复用的实际依赖原因。采用时的数学确认原文随比较保存，不读取后来更新的决定作为本次采用依据。

## 固定版本与保存规则

ComparisonWorkspace 以 options、create、read 提供统一 Interface。HTTP 和验收调用相同实现。create 必须显式接收父运行、子运行、父路线、子路线；缺失版本、外来路线或错误父子关系均被拒绝。

比较记录保存两侧运行清单摘要、精确路线选择、冻结与形式映射身份、采用请求、原数学决定、各类差异及比较实现源码摘要。run_comparisons 仅追加，完整内容进入已有内容寻址存储。相同输入和比较实现重复保存时返回同一身份。

读取保存比较时核对原始输入和摘要，返回原观察结果，不按当前路线或新比较逻辑重新计算。后续切换任一侧路线、生成其他比较或重启工作台，不改变旧比较。

原始记录跳转包括固定路线视图、精确运行 JSON、冻结上下文、Analysis IR、反馈提案和两侧真实证明回执。固定路线参数在反馈历史加载时也会保留，避免跳转过程中退回当前路线。

历史运行未登记的预算、外部调用、费用和耗时显示“未记录”。可从保存事件确定的证明尝试数注明统计来源；未知费用不计算数值差，也不推断为零。比较本身的证明检查提交数固定为零。
