# 前端交互原型

本次只设计页面布局、样式与操作流程。入口与现有工作台分开，不访问后端、模型 API、数据库或 Rocq。

## 打开

在 autoRTA-platform 根目录运行：

```powershell
.\start-prototype.ps1 -Port 8769
```

访问 http://127.0.0.1:8769/prototype.html 。需要 Node.js，无需安装前端依赖。
也可在浏览器中直接打开 `web/prototype.html`；全部脚本和示例资料都在本地。

## 建议先走一遍

1. 首页点击“核对资料”。
2. 点击“查看来源”或“修改”，然后确认模型条件与分析方法。
3. 选择一个或多个目标，点击“进入推导工作台”。
4. 点击节点查看详情；点击“开始演示”，查看并确认排序规则。
5. 点击“查看结果”，查看仍待证明的内容；可以记录修改意见。

## 三个页面

| 页面 | 已可体验的操作 | 后续接入 |
| --- | --- | --- |
| 项目首页 | 打开示例、选择本地 PDF、手动输入、项目搜索和筛选 | 持久保存、真实项目列表 |
| 资料核对 | case_11 原始页图切换、范围说明、字段修改、逐项或本页确认、目标选择 | 通用 PDF 预览与抽取、精准选区、修订和冻结接口 |
| 推导工作台 | 节点详情、图与列表切换、缩放、模拟运行和暂停、明确的数学决定、结果和意见 | 真实双向推理、对齐、提案、运行历史、Rocq 证据、模型费用 |

上传任意 PDF 时只保留用户选择的文件，不生成抽取结果；可手动补充内容。浏览器内嵌预览未接入，提供原文件打开入口。自建项目不会继承 case_11 的条件、推导图或证明结果。

本页修改仅在内存中，刷新会恢复初始示例。演示中的主目标始终不被标为已证明。真实模型调用、证明检查和费用均为 0。

## 文件

- `web/prototype.html`：独立入口。
- `web/prototype.css`：样式和响应式布局。
- `web/prototype.js`：带英文 JSDoc 注释的页面与内存交互。
- `tools/serve-prototype.cjs`：仅允许原型资源、仅监听本机的静态服务器。
- `docs/prototype-direction.md`：已选布局与界面设计目标。
- `DESIGN.md`：本次实际实现的设计规范。

Impeccable 与 Vercel web-design-guidelines 已安装到本机 Codex skills 目录。现有 mattpocock prototype 用于原型约束。此次依据已选方案直接实现，不重新开展样式投票。
