# W05-b：关键数学确认、提案采用与关联新运行

2026 年 11 月 11 日。已接通 W05-a 提案的确认、采用、真实证明检查、证据继承和关联历史。本阶段采用本地规则与已有 Rocq 工具链；没有调用外部模型 API。

## 使用

在项目根目录执行：

~~~powershell
.\check-w05b.ps1
.\start-workbench.ps1 -W05bDemo
~~~

第二条命令启动独立演示目录，首次使用时从最近成功的 W05-b 验收复制数据，后续启动保留演示中的反馈、决定与运行。看到 ready 后打开 http://127.0.0.1:8765/reasoning?run=90ca931fa03f403a8d58b4abe86b4996 。正式工作台仍使用不带演示参数的启动命令。

1. 在推导页面提出反馈，或重开一份已保存提案，先查看具体差异与影响。
2. 对涉及关键数学变化的提案，填写决定人、理由，选择确认、拒绝或要求补充修订并保存。
3. 确认后点击“采用提案并开启关联运行”，设置本轮最多证明检查次数（1–32）和发起人。
4. 完成后自动打开新运行，查看新图、开放义务、本轮用量及每份旧回执的继承或重检原因。
5. 通过“打开原运行”“查看采用的提案与决定”及后续运行链接来回查看历史。刷新后恢复同一保存结果。

同一模型下拆分桥接义务、核对已有条件等提案可以直接采用；若已有拒绝或要求修订的决定，则须重新确认具体方案。反向对齐必须确认后才能采用。尚未形成精确数学内容的范围变更继续等待补充，不能通过点击确认跳过形式化。

## 本轮的数学动作

| 提案 | 采用后的行为 |
|---|---|
| 拆分调度桥接义务 | 新运行增加服务下界和上界；实际检查“下界与上界共同推出原桥接义务”的充分性；保留所有量词、模型前提与截止端点 |
| 核对释放间隔、核对现有对齐 | 保留原数学图，将核对提案作为关联运行输入，重新判断证据是否可用 |
| 反向对齐 | 移除新图中原方向的活动连接；加入精确的反向待证连接；原方向回执和依赖它的组合证明不用于支持新路线 |
| 时间域、模型范围等尚不完整的修改 | 保留请求、影响与缺口，等待形成可执行的精确修订 |

**人工确认只表示接受具体修订方案，不能生成证明。** 反向待证连接仍需实例化和证明；本轮没有实现其证明构造器。

拆分后的联合充分性已通过真实 Rocq 检查与假设审计。这是有两个前提的条件证明，服务下界、服务上界仍是开放义务，Fig.3 接受充分性主目标仍未证明。已登记但尚未编码的其他目标也继续保留。

## 决定、版本与历史

ContinuationWorkspace 提供 review、decide、adopt 和 history，供 HTTP 与验收共用。它内部负责精确修订、确认版本、证据继承和实际执行，复用 W02 的检查器、W03 的映射与 W04 的图接口。

每次决定绑定具体提案、原运行、提案提交时的路线版本、模型范围、精确新图与操作清单。确认内容通过摘要形成稳定 token。拒绝、确认和要求修订均只追加，保留作者、原文理由、前序决定与所审阅计划。使用过期决定或把其他提案的确认用于当前提案，都会被拒绝。

采用另行保存请求与新运行身份，原提案的生成时字段保持原样。W05-a 的 adopted=false 属于原始提案快照，当前采用情况来自独立采用记录。每个关联运行保存：

- 父运行、采用提案、决定、原路线版本、策略与实施源码。
- 新图、节点来源、冻结上下文、语义修订、全部登记目标。
- 本轮检查限额、实际尝试、事件、停止原因与剩余义务。
- 旧回执原始身份、继承去向、排除原因及原历史位置。

本轮可采用的提案没有改变模型合同，因此继续引用同一冻结上下文和形式映射，同时生成独立推导版本。若提案基于历史路线，从该版本建立分支，不覆盖父运行后来选择的路线。

关联执行明确标为读取历史的修订过程（initial_input_isolation=false），不能作为“独立首轮推导没有读取既有证明”的证据。

## 证据继承与用量

旧回执只有在检查环境、上下文、目标版本、精确陈述、联合前提及实际证明依赖仍匹配时才能附到新图。检查器版本或相关实现摘要变化时，新运行建立新检查上下文并重新证明可执行的规则。删除或改变推导关系时，实际依赖它的组合证明重新开放，原回执仍可从历史查看。

证据复用不计为新证明尝试。预算计量单位为 W02 prove/compose 调用，不是底层编译器子进程次数。达到限额、策略暂时耗尽或普通执行异常时，保存部分或失败结果及开放目标，允许以另一笔独立预算再开关联运行。新预算不重置历史用量；旧运行没有记录的费用保持“待核对”，不会推断为零。

同一请求身份携带相同命令重试时返回同一个运行，不重复提交证明；改变内容则必须使用新请求身份。进程被强制中断且尚未保存结果时，登记记录会显示“已登记，尚无完成记录”；本阶段提供查询和历史保留，尚未实现这类中断运行的自动续跑。
