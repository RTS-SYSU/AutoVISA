# 运行所需文档

这里保留程序实际读取、需要随源码分发的文件。普通用户从项目首页 [README](../README.md) 进入工作台。

| 文件 | 用途 |
| --- | --- |
| [case_11 整数时间 DM 数学合同](contracts/case11-integer-dm-soundness.zh.md) | 定义调度模型、假设和待证目标。语义抽取读取合同原文，Analysis IR 核对其 SHA-256，Rocq 检查环境记录该版本。 |

如修改合同，请先核对模型和目标的变化，再更新对应的语义与 IR 配置并重新检查。换行也会影响摘要，仓库将合同固定为 LF。

设计草案、阶段报告、验收笔记及论文样本保留在本地。新增运行所需文档时，请在本页列明实际读取它的模块，并在根目录的 `.gitignore` 中明确允许该文件。
